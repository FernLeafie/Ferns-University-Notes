### Logical operators
A statement is an expression that can be either true of false
$$
\begin{align}
2>1 & \text{ true} \\
2*4=6 & \text{ false}
\end{align}
$$
A statement with a variable is called open
$x>1$ is true for $x=2$ but false $x=1$

Multiple statements can be combined
$x^{2}=1\implies x=\pm1$, this can be written as $x=1\text{ or }x=-1$ but not $x=1\text{ and }x=-1$, but it can be written as $x_{1}=1\text{ and }x_{2}=-1$ through indexing, where the variables are different

For and both statements need to be true for the result to be true
For or to be true, only a single one has to be true

### Implication
implications are supposed to be used when the result can be obtained with two values
$$
\begin{align}
a=b\implies a^{2}=b^{2} \\
-a=b\implies a^{2}=b^{2} \\
a=b\cancel{ \iff  } a^{2}=b^{2}
\end{align}
$$
### Equivalence
If equivalence is to be used both sides must cover all possible alternatives
$$
\begin{align}
x+1=2\iff x=1 \\
x+1=2\cancel{ \iff } x\geq1 \\
x+1=2\impliedby  x\geq1
\end{align}
$$

Implications and equivalence are to be used between statements, while equals is supposed to always be used inside a statement

If any step of a calculation is connected through implication, and not equivalence,  we must check for false roots.
We can cover for them by introducing requirements
$\sqrt{ x+10 }$ only works if $x+10>0\implies x\geq-10$ 
$2+\underbrace{ \sqrt{ x+10 } }_{ \geq0 }=x\implies x\geq2$
